# TGAds — запуск Telegram-каналов и закуп рекламы (Узбекистан)

Веб-панель, которая ведёт через весь цикл:

| # | Модуль | Что делает |
|---|---|---|
| 1 | **Ниши** | Ищет каналы (поиск Telegram, рейтинги и каталог TGStat, импорт списков, «снежный ком» по рекламным постам), считает охваты, ERR и долю рекламы. ИИ определяет тематику. Таблица ниш по спросу и конкуренции. **Креативы, которые покупают повторно** на многих площадках, — значит, они окупаются. ИИ генерирует идеи каналов и рекламные посты по мотивам лучших креативов. |
| 2 | **Контент** | Доноры, лучшие посты по нормированному score (просмотры, пересылки, реакции относительно своего канала), рерайт ИИ или копия с медиа, генерация с нуля, очередь публикаций по слотам. |
| 3 | **Проверка на накрутку** | Аккаунт-монитор вступает в канал, ловит каждый новый пост и снимает просмотры на 30 с, 1, 2, 3, 5, 10, 15, 30, 45 мин, 1–48 ч. Прогноз суток по первым 30 минутам, флаги `late_boost` / `dead_start` / `instant_dump` / `rate_spike`, вердикт и **честный охват**. |
| 4 | **Контакты** | Достаёт @username, телефоны и почты админов из описания и закрепа; приоритет у тех, что рядом со словами «реклама», «reklama» и т.п. Определяет, человек это, бот или прайс-канал. Группирует менеджеров по сеткам каналов. |
| 5 | **Переписка** | Полуавтомат: первое сообщение по шаблону с вариациями, лимиты и паузы. Ответы приходят в панель, цена и формат извлекаются автоматически, CPM считается от честного охвата и даётся рекомендация. ИИ готовит черновик ответа с торгом. Кнопка «Купить». |
| 6 | **Отдача** | Отдельная пригласительная ссылка на каждый закуп. Подписки и отписки за 1, 3 и 7 дней, просмотры рекламного поста, CTR, CPS и цена живого подписчика. Сравнение креативов. |

Подробное ТЗ: [docs/TZ.md](docs/TZ.md).

## Быстрый старт (свой ПК или VPS без Docker)

Нужен Python 3.11+.

```bash
cd tgads
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # впишите TGADS_TG_API_ID и TGADS_TG_API_HASH
python -m tgads           # панель: http://127.0.0.1:8080
```

`api_id` и `api_hash` берутся на https://my.telegram.org → API development tools (один раз на любой аккаунт).

Дальше в панели: **Аккаунты** → номер → код из Telegram (и облачный пароль, если есть 2FA) → назначить роли.

## ИИ без API-ключа

Софт вызывает установленный на сервере **Claude Code** (`claude -p`), а тот работает по вашей подписке Claude:

```bash
npm install -g @anthropic-ai/claude-code
claude          # один раз войти в аккаунт Claude, потом выйти (/exit)
```

После этого `TGADS_AI_MODE=auto` сам выберет Claude Code. Если Claude Code не установлен, включается **ручной режим**: на странице «ИИ» у каждой задачи есть промпт, его копируют в чат с Claude, а ответ вставляют обратно.
Если появится API-ключ, впишите `TGADS_ANTHROPIC_API_KEY`, и режим переключится на API.

## Сервер (VPS) — доступ с телефона 24/7

Нужен VPS с Ubuntu 22.04/24.04: 2 ГБ RAM и 20 ГБ диска хватит, локация любая (подойдёт Европа). На сервере, под root:

```bash
curl -fsSL https://raw.githubusercontent.com/Failbringer1/ppp/claude/telegram-channel-ads-platform-8qn7b8/tgads/deploy/install.sh | sudo bash
```

Скрипт ставит Docker, скачивает код и спрашивает `api_id` и `api_hash`. Если домена нет, просто нажмите Enter: адрес будет вида `https://1-2-3-4.sslip.io` (IP через дефисы), HTTPS-сертификат получится автоматически.
В конце скрипт печатает адрес панели, логин и пароль. Пароль хранится в `/opt/tgads/tgads/.env`.

После установки один раз войдите в Claude, чтобы ИИ работал без API-ключа:

```bash
cd /opt/tgads/tgads && docker compose exec -it tgads claude    # /login → ссылка → код → /exit
```

На телефоне откройте адрес панели и выберите «Добавить на главный экран»: панель будет открываться как приложение.
Обновление — та же команда установки: код подтянется, база и настройки останутся.

Процесс должен работать **постоянно**: монитор ловит первые минуты постов, а лог отписок Telegram хранит всего 48 часов.

## Windows-сервер (рядом с другими сайтами за Caddy)

Если сервер на Windows и на нём уже работает Caddy с другими сайтами (как на сервере Morningstar Lab), откройте PowerShell **от имени администратора** (через RDP или `ssh Administrator@сервер`) и выполните:

```powershell
[Net.ServicePointManager]::SecurityProtocol = 'Tls12'
& ([scriptblock]::Create((irm 'https://raw.githubusercontent.com/Failbringer1/ppp/claude/telegram-channel-ads-platform-8qn7b8/tgads/deploy/windows/install.ps1'))) -ApiId ВАШ_API_ID -ApiHash ВАШ_API_HASH
```

Что делает установщик:
- Всё ставит в `C:\Apps\TGAds`: отдельный Python, зависимости, Chromium для TGStat, Claude Code. Python и файлы других приложений не трогает.
- Создаёт задачу Windows «TGAds» от `LocalService`: автозапуск при старте Windows, перезапуск при сбое. Панель слушает только `127.0.0.1`.
- Добавляет в Caddyfile работающего Caddy **один** новый блок для адреса `https://<IP-через-дефисы>.sslip.io`. Перед этим делается резервная копия `Caddyfile.bak-tgads-*`, затем `caddy validate`. Если конфиг не прошёл проверку, файл возвращается как был. Существующие сайты не меняются.
- Печатает адрес, логин и пароль панели. В конце предлагает получить токен Claude (`claude setup-token`), чтобы ИИ работал без API-ключа. Токен можно вставить и позже: «Настройки» → Claude.

Повторный запуск той же команды обновляет код, а данные и настройки сохраняются. Логи лежат в `C:\Apps\TGAds\logs\`.

**Доступ к серверу для Claude.** Добавьте к команде `-RunnerRepo владелец/приватный-репозиторий`. Установщик первым делом зарегистрирует на сервере раннер GitHub Actions: служба от SYSTEM, метка `tgads-ops`, токен регистрации берётся через `gh`, если он авторизован на сервере. После этого Claude может выполнять команды на сервере, пушая скрипты в ветку `claude-ops` этого репозитория, и читать результат в логах Actions. Без SSH и без постоянно открытых портов.
Используйте **только приватный** репозиторий: любой, кто может в него пушить, управляет сервером.

## TGStat

Страница «Ниши» → блок **TGStat**. Можно собрать рейтинг каналов Узбекистана по категории или по любому адресу страницы TGStat со списком: все каналы встанут в очередь сбора.
На странице «Каналы» есть действие «Подтянуть цифры TGStat»: подписчики, средний охват, ERR, индекс цитирования, упоминания и пометки о накрутке. Цифры видны в карточке канала.

- Скачивание идёт аккуратно: одна страница в 4–9 секунд, кэш на 12 часов, лимит 300 страниц в день (меняется в «Настройках»).
- Если TGStat закрыт проверкой Cloudflare, страница открывается через встроенный headless-браузер (в Docker-образе он уже есть).
- Если не пускает и браузер, откройте страницу TGStat в своём браузере, скопируйте её HTML и вставьте в поле «Разобрать HTML».
- Если TGStat поменяет вёрстку, на странице «Отладка TGStat» будет видно, что именно не распозналось.

Учтите: TGStat не любит автоматический сбор, при слишком частых запросах IP сервера могут ограничить.

## Порядок работы

1. **Аккаунты.** Роли: `monitor` (вступает в каналы и замеряет просмотры, до ~500 каналов на аккаунт), `outreach` (пишет админам, лучше аккаунт с историей), `publisher` (админ ваших каналов).
2. **Ниши.** Поиск по ключевым словам и импорт списков (например, из `uz.tgstat.com`), затем «Определить тематики ИИ», «Пересобрать креативы» и «Сгенерировать идеи».
3. **Контент.** Добавить свой канал (язык `uz`, `uz_cyrl` или `ru`), доноров, обновить их посты, взять лучшие в рерайт и поставить в очередь.
4. **Каналы → «Отправить на проверку накрутки».** Через 1–3 дня на странице «Проверка» появятся вердикты и честный охват.
5. Чистые каналы → «Найти контакты админов» → «Запросить цену у админов».
6. **Переписка:** ответы, разобранные цены, CPM, «Купить». Закуп создаёт трекинг-ссылку и текст для админа с этой ссылкой.
7. **Закупы:** подписчики, отписки, CPS и сравнение площадок и креативов.

## Настройки, которые стоит проверить

- Курсы USD/RUB → сум и **целевой CPM**: от него считаются рекомендации и «справедливая цена».
- Лимиты: вступлений в день (30), новых диалогов в день (15), паузы между сообщениями, рабочие часы.
- Пороги детектора накрутки. Начальные значения стоит откалибровать на своих данных: через 1–2 недели нажмите «Пересчитать эталонные кривые».

## Риски

- Telegram ограничивает частоту запросов (FloodWait) и банит за спам. Все запросы идут с паузами и лимитами, но рассылка незнакомым людям всё равно может принести спамблок. Используйте отдельные аккаунты, не основной.
- Копирование чужих постов «как есть» может вызвать жалобы. По умолчанию лучше рерайт.

## Разработка

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты покрывают аналитику (кривые, прогноз, детектор накрутки, цены, контакты, креативы, ниши), полный сценарий модулей 1–6 на фейковом Telegram-клиенте и рендер всех страниц.

Структура: `tgads/analysis` — чистая логика без сети, `tgads/services` — сценарии модулей, `tgads/tg` — Telethon, `tgads/ai` — провайдеры и очередь ИИ-задач, `tgads/web` — панель.
