# TGAds — запуск Telegram-каналов и закуп рекламы (Узбекистан)

Веб-панель, которая ведёт через весь цикл:

| # | Модуль | Что делает |
|---|---|---|
| 1 | **Ниши** | Ищет каналы (поиск Telegram, импорт списков, «снежный ком» по рекламным постам), считает охваты, ERR и долю рекламы. ИИ определяет тематику. Таблица ниш по спросу и конкуренции. **Креативы, которые покупают повторно** на многих площадках, — значит, они окупаются. ИИ генерирует идеи каналов и рекламные посты по мотивам лучших креативов. |
| 2 | **Контент** | Доноры, лучшие посты по нормированному score (просмотры, пересылки, реакции относительно своего канала), рерайт ИИ или копия с медиа, генерация с нуля, очередь публикаций по слотам. |
| 3 | **Проверка на накрутку** | Аккаунт-монитор вступает в канал, ловит каждый новый пост и снимает просмотры на 30 с, 1, 2, 3, 5, 10, 15, 30, 45 мин, 1–48 ч. Прогноз суток по первым 30 минутам, флаги `late_boost` / `dead_start` / `instant_dump` / `rate_spike`, вердикт и **честный охват**. |
| 4 | **Контакты** | Достаёт @username, телефоны и почты админов из описания и закрепа; приоритет у тех, что рядом со словами «реклама», «reklama» и т.п. Определяет, человек это, бот или прайс-канал. Группирует менеджеров по сеткам каналов. |
| 5 | **Переписка** | Полуавтомат: первое сообщение по шаблону с вариациями, лимиты и паузы. Ответы приходят в панель, цена и формат извлекаются автоматически, CPM считается от честного охвата и даётся рекомендация. ИИ готовит черновик ответа с торгом. Кнопка «Купить». |
| 6 | **Отдача** | Отдельная пригласительная ссылка на каждый закуп. Подписки и отписки за 1, 3 и 7 дней, просмотры рекламного поста, CTR, CPS и цена живого подписчика. Сравнение креативов. |

Подробное ТЗ: [docs/TZ.md](docs/TZ.md).

## Быстрый старт (свой ПК или VPS без Docker)

Нужен Python 3.11+.

```bash
cd tgads
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # впишите TGADS_TG_API_ID и TGADS_TG_API_HASH
python -m tgads           # панель: http://127.0.0.1:8080
```

`api_id` и `api_hash` берутся на https://my.telegram.org → API development tools (один раз на любой аккаунт).

Дальше в панели: **Аккаунты** → номер → код из Telegram (и облачный пароль, если есть 2FA) → назначить роли.

## ИИ без API-ключа

Софт вызывает установленный на сервере **Claude Code** (`claude -p`), а тот работает по вашей подписке Claude:

```bash
npm install -g @anthropic-ai/claude-code
claude          # один раз войти в аккаунт Claude, потом выйти (/exit)
```

После этого `TGADS_AI_MODE=auto` сам выберет Claude Code. Если Claude Code не установлен, включается **ручной режим**: на странице «ИИ» у каждой задачи есть промпт, его копируют в чат с Claude, а ответ вставляют обратно.
Если появится API-ключ, впишите `TGADS_ANTHROPIC_API_KEY`, и режим переключится на API.

## VPS через Docker

```bash
cd tgads
cp .env.example .env      # api_id/api_hash + обязательно TGADS_PANEL_PASSWORD
docker compose up -d --build
docker compose exec tgads claude    # один раз войти в Claude (логин сохранится в ./data/claude)
```

Панель слушает только `127.0.0.1:8080`. Открывать её через SSH-туннель (`ssh -L 8080:127.0.0.1:8080 user@vps`) или через reverse-proxy с HTTPS.
Процесс должен работать **постоянно**: монитор ловит первые минуты постов, а лог отписок Telegram хранит всего 48 часов.

## Порядок работы

1. **Аккаунты.** Роли: `monitor` (вступает в каналы и замеряет просмотры, до ~500 каналов на аккаунт), `outreach` (пишет админам, лучше аккаунт с историей), `publisher` (админ ваших каналов).
2. **Ниши.** Поиск по ключевым словам и импорт списков (например, из `uz.tgstat.com`), затем «Определить тематики ИИ», «Пересобрать креативы» и «Сгенерировать идеи».
3. **Контент.** Добавить свой канал (язык `uz`, `uz_cyrl` или `ru`), доноров, обновить их посты, взять лучшие в рерайт и поставить в очередь.
4. **Каналы → «Отправить на проверку накрутки».** Через 1–3 дня на странице «Проверка» появятся вердикты и честный охват.
5. Чистые каналы → «Найти контакты админов» → «Запросить цену у админов».
6. **Переписка:** ответы, разобранные цены, CPM, «Купить». Закуп создаёт трекинг-ссылку и текст для админа с этой ссылкой.
7. **Закупы:** подписчики, отписки, CPS и сравнение площадок и креативов.

## Настройки, которые стоит проверить

- Курсы USD/RUB → сум и **целевой CPM**: от него считаются рекомендации и «справедливая цена».
- Лимиты: вступлений в день (30), новых диалогов в день (15), паузы между сообщениями, рабочие часы.
- Пороги детектора накрутки. Начальные значения стоит откалибровать на своих данных: через 1–2 недели нажмите «Пересчитать эталонные кривые».

## Риски

- Telegram ограничивает частоту запросов (FloodWait) и банит за спам. Все запросы идут с паузами и лимитами, но рассылка незнакомым людям всё равно может принести спамблок. Используйте отдельные аккаунты, не основной.
- Копирование чужих постов «как есть» может вызвать жалобы. По умолчанию лучше рерайт.
- TGStat не парсится (Cloudflare и правила сервиса). Списки каналов из их каталога можно вставить через импорт.

## Разработка

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты покрывают аналитику (кривые, прогноз, детектор накрутки, цены, контакты, креативы, ниши), полный сценарий модулей 1–6 на фейковом Telegram-клиенте и рендер всех страниц.

Структура: `tgads/analysis` — чистая логика без сети, `tgads/services` — сценарии модулей, `tgads/tg` — Telethon, `tgads/ai` — провайдеры и очередь ИИ-задач, `tgads/web` — панель.
